Exam Preparation: Summary of Core Concepts

R Basics

Objects and Functions

  • Objects: Containers for data, models, columns, and variables
  • Functions: Operations performed on objects; arguments can be named or unnamed (default order assumed)
  • Naming convention: data_your_name <- value
  • Pipe operator (%>%): Passes output of one function as input to the next

Data Visualization with ggplot2

  • Layer-based approach: Build plots by adding layers sequentially
  • Essential layers: Data → aesthetics (aes()) → geometry (geom_*())
  • Flexibility: Combine data from different data frames in a single plot

Statistical Models

What is a Model?

A probabilistic representation of how data are generated by underlying processes. The model captures: - Systematic component: How explanatory variables predict the response - Random component: Remaining variance (residuals) assumed to be normally distributed

Model Notation

\(y \sim \text{Normal}(\mu, \sigma)\) \(\mu = a + b \cdot x\)

In R: lm(response ~ explanatory_variables)

Key Concepts

Response variable: The variable you want to explain/predict.

Explanatory variables: Variables describing underlying processes: - Categorical (e.g., site, treatment, species) → test differences between groups - Numerical (e.g., temperature, age) → test dependency relationships

Effect types: - Additive (+): Variables act independently - Interactive (*): One variable modifies how another affects the response

Model Output

Output Interpretation
p-value Probability of observing your data if explanatory variables had no effect. p < 0.05 → significant effect
R² Proportion of variance in response explained by the model (0–1 scale)
Coefficients From summary(model) → intercept, slopes, and their significance
ANOVA table From anova(model) → test overall impact of each explanatory variable

Post-Hoc Tests

After ANOVA finds a significant effect, post-hoc tests identify which specific groups differ.

Multiple Comparisons Problem

  • Issue: Comparing many group pairs inflates “false positives” (assume impact of explanatory variables if in reality, no impact exists)
  • Example: 3 groups = 3 pairwise comparisons. If each has 5% error risk, total error risk ≈ 14%
  • Solution: Apply p-value adjustment (add small value as “penalty”), depending on number of comparisons.

In R

estimate_contrasts(model, p_adjust = "tukey") provides adjusted p-values and confidence intervals for pairwise comparisons.

Model Assumptions

1. Independence

Each observation is statistically independent; no hidden structure linking observations.

Violations: - Hierarchical data (replicates within sites) - Repeated measurements of same individual - Spatial autocorrelation (nearby points more similar) - Temporal autocorrelation (time series)

Check: Think about how data was collected.

2. Homoscedasticity (Equal Variance)

Variance (spread) in residuals is constant across all groups and predicted values.

Model assumes: \(y \sim \text{Normal}(\mu, \sigma)\) with one σ value for all data.

Violations: Variance increases/decreases with group or with fitted values (e.g., heteroscedastic data).

Check: “Homogeneity of Variance” plot should show points evenly scattered around reference line; no funnel/wedge pattern.

3. Normality

Residuals (variablity/errors left after model) follow a normal distribution.

Why: Linear model derives confidence intervals and p-values assuming normal errors.

Violations: Residuals heavily skewed, bimodal, or have extreme outliers.

Check: “Normality of Residuals” Q-Q plot — points should fall along the line. Slight deviations acceptable; major deviations problematic.
